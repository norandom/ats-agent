## Project Description (Input)
The repository owner wants to migrate the existing Python PDF CV scorer into a skill-based application workflow using uv/uvx where external tooling is needed. The user will supply a CV to establish a private, Git-ignored fact base, then paste a job offer for each application. The system should interpret employer needs, develop a persuasive contribution narrative, align truthful occupational terminology for human and automated readers, and produce an ATS-readable DOCX using WordCraft MCP. Professional HR and occupational-psychology sources must ground the methodology. Facts constrain claims without forcing the final document into an unattractive inventory. The existing value-add orientation should be preserved. See brief.md and research.md for scope, source quality and unresolved integration questions.
